## Overview

UPS Manager reads the UPS devices on your hosts and shows the battery charge, runtime, load and voltage in a tab. Termix keeps a history, logs every power event and sends an alert when power is lost, the battery runs low or the UPS is overloaded.

Read the [docs](https://docs.termix.site/plugins/ups-manager) to set it up and use it.

<br />

## Features

- NUT, apcupsd and SNMP cards
- Battery charge, runtime, load, voltage and temperature
- Charts for 24 hours, 7 days and 30 days
- Alerts for power loss, low battery, replace battery, overload and failed tests
- A power event log for every UPS
- Battery self test, beeper and other NUT commands
- A dashboard card with every UPS on your hosts
- Power status, charge and runtime as status tiles
